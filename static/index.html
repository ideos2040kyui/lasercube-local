APC40 · HORROR SETUP

どこを動かすと、どうなる？

RED HANDS

おすすめの割り当てです。まず「MIDIを接続」。各行の「割り当て」を押してから、APC40の該当箇所を動かしてください。

APC40のどこ割り当てる操作起こる動き
左端のフェーダーわらわら度手が1体 → 8体に増える
左から2本目のフェーダー明るさ赤い手を暗く／明るくする
左から3本目のフェーダー大きさ手形の群れ全体を拡大／縮小
使いやすいノブ1つ動く速さ手の揺れ・うごめきが速くなる
左上のクリップボタン開始停止するまで出力を続ける
その真下のクリップボタン停止出力を停止する

「赤い手形」を選ぶと赤い手の輪郭が現れます。手を増やすと実機ではちらつく場合があります。実機の出力許可は画面で行います。

OSC BRIDGE

アプリ同士をつなぐ

同じMac上のアプリとOSC / UDPでつなぎます。送信と受信は個別に使えます。

CC → /apc40/cc/チャンネル/番号
ボタン → /apc40/note/チャンネル/番号
値は0〜1。MIDIの入力接続も必要です。

送信 0—

/laser/brightness · /laser/size · /laser/speed に0〜1を送ります。
/laser/start / /laser/stop で開始・停止。実機の出力許可は画面で行います。

受信 0—

LaserCube Local Studio ローカル専用 · 停止操作まで継続可能 · 通信断・過熱停止時は自動停止
