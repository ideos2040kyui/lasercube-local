# LaserCube Local Studio

macOS向けのLaserCube操作画面です。最終版の素材・演出設定を同梱し、機器なしで使えるデモモードで起動します。
APC40のMIDI入力と、同じMac上の別アプリとのOSC送受信に対応しています。

## この最終演出をそのまま再現する

Git clone後に起動するだけで、素材の変換や読み込みは不要です。
`assets/`に血糊・扇子・部屋の元GIFと変換済み輪郭、`shows/`に版ごとの演出設定を含めています。
起動時はメーター100%・連動ONのデモ表示です。「蛇行線の長さ」を100→95→90→50→0へ下げると最終演出を確認できます。

- 90%以上：外周のピンクのハートだけ。95%から90%で薄くなり、メーターもピンク。
- 90%未満：外周だけに手形と小さい血糊。低下するほど数が増えます。
- 50%未満：中央に大きな血糊を1つ。中央には手形を置きません。
- 0%：外周に手形24体・小さい血糊8個。下に赤い扇子3つが横並びで出現。目と瞳を強調しています。

起動だけで実機を発光させることはありません。実機にはLAN接続、画面での出力許可、開始操作が必要です。
起動設定は`shows/v1.json`・`shows/v2.json`内の`preset`で確認・変更できます。APC40の割り当ては機器に合わせてMIDI学習してください。

## v1 / v2を切り替える

画面上部の「v1 · オリジナル」「v2 · 手形 → 血糊」で切り替えます。
切り替え時は出力を停止して出力許可を解除します。各版の操作値はサーバー起動中、別々に記憶します。

- v1：これまでの完成版。ハート、手形と血糊の重ね合わせ、0%の扇子3つを維持しています。
- v2：中央の`room2.gif`は常時ループ（60コマ・4秒）。90%以上は周りにハート、90%未満〜50%以上は外周の手形が増えます。50%未満で手形を消し、中央に血糊1つを重ねます。周囲の小さい血糊と扇子は出しません。部屋の外形は白、扉・床の色の境界は赤・青の線で描き、塗り面や細いひびは省略します。

素材は共用し、演出の配置・条件・開始設定は`shows/v1.json`と`shows/v2.json`に分けています。
通常はv1で起動します。v2で起動する場合は`python3 app.py --show v2 --open`を使えます。
完成時点の元のv1ソースはGitタグ`v1`（`bd0cc41`）にも保存しています。

## 起動

macOSとPython 3.9以降が必要です。取得する場合は次のとおりです。

```sh
git clone https://github.com/ideos2040kyui/lasercube-local.git
cd lasercube-local
./起動.command
```

Finderでこのフォルダの `起動.command` をダブルクリックします。
ブラウザに http://localhost:8765 が開きます。
Google ChromeまたはMicrosoft Edgeが入っていれば、MIDI入力に対応するそのブラウザを開きます。
MIDI以外のデモ・画面操作はSafariでも使えます。

追加のPythonパッケージのインストールは不要です。このMacではCommand Line ToolsのPython 3を使っています。
ターミナルから起動する場合は次のとおりです。

```sh
cd lasercube-local
python3 app.py --open
```

起動したターミナルでControl+Cを押すと終了します。
すでに起動している状態でも、起動.commandは同じアプリの画面を開きます。

## まずデモで試す

1. 出力先の「デモ」を選びます。起動直後は必ずデモです。
2. 「蛇行線の長さ」を動かし、ハート・血糊・外周の手形・0%の扇子を確認します。
3. 単独の図形を試す場合は「メーターでハート・ホラーを切り替える」をOFFにし、円などを選びます。
4. 「デモを開始」で開始と停止を確認します。初期設定では停止操作まで継続します。デモは本体に出力命令を送りません。

## APC40の接続と割り当て

1. APC40をUSBでMacへつなぎます。
2. Chrome / Edgeで画面を開き「MIDIを接続」を押し、MIDIアクセスを許可します。
3. 機器一覧からAPC40を選びます。接続されていれば自動的に優先選択します。
4. 「明るさ」などの操作を選び「操作を覚える」を押します。
5. APC40のフェーダー・ノブ・ボタンを1つ動かすと割り当てられます。

明るさ・大きさ・速度・わらわら度にはフェーダー／ノブ、開始・停止・図形切替にはボタンを使ってください。
MIDIチャンネルとCC／ノート番号で対応付けるため、APC40とAPC40 MKIIのどちらにも対応します。
割り当てはそのブラウザのローカルストレージへ保存します。APC40へのLEDフィードバックは未実装です。
APC40の実機入力は、接続後に「最後の入力」の値が変わることで確認できます。

## 赤い手形のホラーモード

「赤い手形」を選ぶと赤色に変わり、左右の手の輪郭がゆっくり揺れ、濃くなったり薄くなったりします。
「わらわら度」は手の数（1〜8体）です。増やすと同時に描く手が増えます。
実機はレーザーによる輪郭描画です。手の数が増えるとちらつく場合があります。

APC40のおすすめ割り当ては画面の「どこを動かすと、どうなる？」にも表示しています。

| APC40の操作 | 割り当て | 動き |
| --- | --- | --- |
| 左端のフェーダー | わらわら度 | 手の数1〜8体 |
| 左から2本目のフェーダー | 明るさ | 暗く／明るくする |
| 左から3本目のフェーダー | 大きさ | 手形の群れ全体を拡大／縮小 |
| 使いやすいノブ1つ | 動く速さ | 手の揺れと明滅をゆっくり／速くする |
| 左上のクリップボタン | 開始 | 停止操作まで継続 |
| その真下のクリップボタン | 停止 | 出力を停止 |

各行の「割り当て」を押してから、該当するAPC40の箇所を動かして覚えさせます。
初期状態でAPC40の固定番号に自動割り当てする方式ではありません。

## SVGを映す

「SVGを読み込む」で2MB以内のSVGを選ぶと、輪郭のプレビューに切り替わります。
読み込み時は実行中の出力を停止し、出力許可を解除します。確認後に改めて開始してください。
別の図形に切り替えた後は「SVGを表示」で戻れます。最後に読み込んだSVGは`.runtime/`へローカル保存します。
再起動時もSVGデータは残りますが、デモモードで起動し、出力は開始しません。

塗り・陰影は輪郭線になり、色は画面の色設定を使います。「白・淡色の背景を除く」は読み込み時に適用します。
`path`（直線・ベジェ曲線・円弧）、円、楕円、矩形、ポリライン、多角形と基本変換に対応します。
文字は事前にパス化してください。画像、外部参照、クリップ、マスク、CSSでの装飾は再現しません。
番号付きの`g.f0`、`g.f1`…をCSSのvisibilityで切り替えるコマ形式は、最大120コマまで繰り返し再生できます。
一般的なCSS/SMILアニメーション全体を再生する機能はありません。
アニメーションSVGの速度は0〜1倍（0ならコマを固定）、静止SVGの速度は回転速度です。
各コマを最大24輪郭・800点（輪郭間の消光移動を含む）に制限し、細部を省くことがあります。
複雑な図形は実機ではちらついたり、角が丸く見えたりします。今回のSVGの実機投影は未確認です。

制作者へは、塗りなしの単純な輪郭、背景・陰影なし、少ないパーツでの制作を依頼してください。
同梱している最終素材は`assets/`内です。ローカルで読み込んだSVGやGIFの作業データは`.runtime/`に保存し、Git管理から除外します。
[SVGのパス仕様](https://www.w3.org/TR/SVG/paths.html)に基づいて輪郭を読み取ります。

## 手形・SVGをレイヤーで重ねる

「手形も、bloodも、一緒に。」の「重ねて表示」でレイヤーA・Bを合成します。
各レイヤーに手形、円、8の字、三角形、SVGを選べます。SVGは各レイヤーの「SVGを読み込む」で別々のファイルを設定できます。
各レイヤーの表示、明るさ、大きさ、速度、手の数、色、横位置・縦位置は独立しています。
上部の明るさ・大きさ・速度は全体にかかります。レイヤーの明るさ100%は全体の明るさと同じ出力です。
手の数は手形で、速度は手形の動き・基本図形の回転・アニメーションSVGの再生に使います。
レイヤーSVGが未指定なら単独表示用のSVGを使い、どちらもなければそのレイヤーは描きません。
重なった輪郭は両方とも見えます。塗りによる遮蔽はありません。
合成時は最大1000点へ簡略化するため、細部やちらつきは実機で確認してください。

APC40は「A：明るさ」「B：明るさ」などをそれぞれ別のフェーダーへ学習できます。
初期のおすすめは、左端=Aの明るさ、2本目=Bの明るさ、3本目=Aの手の数、ノブ=Bの速度です。
レイヤー別SVGはローカルの`.runtime/layer-a-svg.json`・`layer-b-svg.json`へ保存し、起動時に読み込みます。

## 右上のどきどきメーター

「右上に表示」をONにすると、電池型のメーターがプレビューと実機出力の右上に現れます。
「蛇行線の長さ」スライダーで、固定した蛇行線の見える長さを0〜100%に変えます。
外枠・線の太さ・折り返しの間隔はそのままで、先端から線が短くなります。0は外枠だけ、100は線全体を表示します。
手形・SVGやレイヤーの大きさ・位置・速度には連動しません。全体の明るさと停止操作は共通です。
「メーターの明るさ」でメーターだけを暗くできます。
「メーターをAPC40に割り当て」を押してフェーダーを動かすと、手元から量を変更できます。
MIDI割り当て一覧にはメーターの量・明るさ・表示切替もあります。
輪郭と内部の走査線で量を表し、メーターを含む合成は最大1200点に制限します。

## メーター連動のハート・ホラー演出

「メーターでハート・ホラーを切り替える」をONにすると、手動レイヤーに代わり、メーターの値だけで演出が変わります。

| メーター | 演出 |
| --- | --- |
| 90%以上 | 外周にピンクのハート5個だけ。95%から90%にかけて薄くなる。メーターはピンク。扇子・手形・血糊なし |
| 50%以上〜90%未満 | 外周だけに小さい血糊と手形。下がるほど数と濃さが増える |
| 0%超〜50%未満 | 中央にも大きな血糊を1つだけ表示。増える血糊は周囲に配置 |
| 0% | 手形24体、周囲の血糊8個、中央の血糊1つ。画面下に赤い扇子GIFを3つ横並びで表示。目と瞳を強調 |

90%ちょうどはハート、50%ちょうどは中央の血糊なしです。
手形は外周だけに配置し、中央には出しません。中央の血糊は重ねず、0%では扇子と重なりにくいよう少し上へ寄せます。
扇子は細かい骨組みを省き、目の輪郭と瞳を大きく再構成しています。0%の描画では扇子の線を優先配分し、メーター込みの上限1200点を維持します。
GIFが取り込み済みなら血糊GIFの全コマとフェードを再生します。扇子は0%限定で、0%へ戻るたびに出現・開閉の再生をやり直します。
血糊GIFが未設定ならレイヤーBのSVG（未指定なら単独表示のSVG）の最後のコマを使います。
全体の明るさ・大きさ・速度と停止操作は共通です。出力の開始や許可を自動で行う機能ではありません。
APC40の既存の「蛇行線の長さ」への割り当てをそのまま使えます。
連動をOFFにすると、元の手動レイヤー設定へ戻ります。輪郭数が増えるほど細部は簡略化されます。

## 血糊・扇子・部屋のGIF素材

`assets/blood4.gif`を血糊、`assets/openEyes.gif`を扇子、`assets/room2.gif`をv2中央の部屋として使用しています。変換済みの`effect-blood.json`・`effect-fan.json`・`effect-room.json`も同梱しています。
次のコマンドで差し替えたGIFをレーザー用輪郭へ変換し、アプリを再起動すると反映します。

```sh
python3 gif_import.py assets/blood4.gif assets/openEyes.gif --room assets/room2.gif
```

変換にはmacOSのImageIOとCommand Line ToolsのSwiftを使用します。Pythonの追加パッケージは不要です。
1ファイル12MB、400コマ、各辺800px、合計4000万画素までを読み込みます。
各コマの時刻と透明度の変化を維持し、白・淡色の背景を取り除いて輪郭に変換します。
塗りや写真の陰影は再現できず、複数配置時は輪郭や細部を走査点数に合わせて省略します。
変換データは`.runtime/effect-blood.json`・`effect-fan.json`・`effect-room.json`に保存します。元のGIFは変更しません。

## LaserCube実機

1. Mac → USB-Cハブ → LANケーブル → LaserCubeのLAN端子へ接続します。
2. 本体をLAN Serverモードにします。Macの有線LANはDHCP（自動取得）を使います。
3. インターネットと併用するときは、Macのネットワークサービス順序でWi-Fiを有線LANより上にします。
4. 接続欄にモデル名と温度が表示されることを確認します。初期接続先は192.168.1.1です。
5. 他のレーザー制御アプリを終了し、投影先と緊急停止手段を確認します。
6. 「LaserCube実機」を選び、確認欄をチェックして「実機への出力操作を許可」を押します。
7. 「実機出力を開始」で開始します。停止ボタンまたはEscapeキーで停止できます。

同梱演出プリセットは明るさ5%・大きさ30%です。出力上限5%、図形サイズ5〜30%、最大12000ppsに制限しています。
実行時間の初期値は「停止するまで」です。必要に応じて5秒・15秒・30秒のタイマーを選べます。
この値は目の安全を保証するものではありません。低出力でも危険です。
本体のインターロックが未有効、過熱停止フラグがON、機器への応答なしの場合は開始できません。
温度警告フラグは画面に表示します。警告だけでは開始を禁止せず、過熱停止フラグがONになったときは実行中の出力も停止します。
画面の接続が3秒以上途切れたとき、タイマーを選んだ場合の指定時間終了時、サーバー終了時にも停止命令を送ります。
各フレームの先頭と末尾は消光した点を送ります。
画面と実機の上下を合わせるため、SVG・手形・基本図形を含むすべての実機送信でY座標を変換します。
OSの停止・電源断・ネットワーク断などでソフトウェア停止命令が届かない場合があるため、本体の緊急停止手段を使用してください。

初版は図形送信とMIDI入力に絞った実装です。メーカーアプリと同じ投影範囲・安全ゾーン・光学補正は提供しません。
APC40で開始を割り当てても、実機モードでは先に画面で出力操作を許可する必要があります。

## OSCで別アプリとつなぐ

画面下部の「アプリ同士をつなぐ」で設定します。起動時は送信・受信ともOFFです。
この版は同じMac内の127.0.0.1で通信します。別PCからの受信や別PCへの送信には未対応です。

### APC40 → 別アプリへ送信

1. MIDI接続を済ませ、「APC40の操作を別アプリへ送る」をONにします。
2. 送信先ポートを指定します。初期値は9001です。
3. 「設定を適用」を押します。
4. 相手アプリをUDPポート9001でOSC受信する設定にします。

MIDIの割り当ての有無にかかわらず、選択中のMIDI機器の入力を送ります。

| 入力 | OSCアドレス例 | 引数 |
| --- | --- | --- |
| CH1のCC7 | `/apc40/cc/1/7` | 0〜1のfloat |
| CH1のノート53 | `/apc40/note/1/53` | 0〜1のfloat（離すと0） |

連続するCC入力は最大約60回/秒にまとめ、最後の値を送ります。ボタンの押下・解放は個別に送ります。

### 別アプリ → LaserCubeへ受信

1. 「別アプリからLaserCubeを操作する」をONにして「設定を適用」を押します。
2. 相手アプリのOSC送信先を127.0.0.1、UDPポート9000にします。
3. デモモードで値が画面へ反映されることを確認します。

| OSCアドレス | 引数 | 動作 |
| --- | --- | --- |
| `/laser/brightness` | float 0〜1 | 明るさ0〜5% |
| `/laser/size` | float 0〜1 | 大きさ5〜30% |
| `/laser/speed` | float 0〜1 | 回転速度0〜1回転/秒 |
| `/laser/shape` | string | `circle` / `eight` / `triangle` / `hands` / `layers` / `svg`（読込後） |
| `/laser/density` | float 0〜1 | 手形の数1〜8体 |
| `/laser/colour` | string | `#57e5dc`などのRGB色 |
| `/laser/duration` | intまたはfloat | 0なら停止するまで継続、5〜30なら指定秒数 |
| `/laser/next` | なし、または1 | 次の図形 |
| `/laser/start` | なし、または1 | 開始 |
| `/laser/stop` | なし、または1 | 停止 |

実機の出力許可は引き続きブラウザ画面で行います。OSCから出力許可を有効にする機能はありません。
即時実行のOSC bundleにも対応します。未来時刻のスケジュール、アドレスのワイルドカード、全OSC型には対応していません。
OSC入力は最大400メッセージ/秒です。送受信のポート番号は別々にします。

受信をONにした後、ターミナルから次の例で回転速度を変更できます。出力開始の命令は送りません。

```sh
cd lasercube-local
python3 -c 'import socket; from osc_protocol import encode_message; socket.socket(socket.AF_INET,socket.SOCK_DGRAM).sendto(encode_message("/laser/speed",[0.3]),("127.0.0.1",9000))'
```
