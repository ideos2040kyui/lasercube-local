# LaserCube Local Studio

このMac専用のLaserCube操作画面です。機器なしで使えるデモモードで起動します。
APC40のMIDI入力と、同じMac上の別アプリとのOSC送受信に対応しています。

## 起動

macOSとPython 3.9以降が必要です。取得する場合は次のとおりです。

```sh
git clone https://github.com/ideos2040kyui/lasercube-local.git
cd lasercube-local
./起動.command
```

Finderでこのフォルダの `起動.command` をダブルクリックします。
ブラウザに http://localhost:8765 が開きます。
Google ChromeまたはMicrosoft Edgeが入っていれば、MIDI入力に対応するそのブラウザを開きます。
MIDI以外のデモ・画面操作はSafariでも使えます。

追加のPythonパッケージのインストールは不要です。このMacではCommand Line ToolsのPython 3を使っています。
ターミナルから起動する場合は次のとおりです。

```sh
cd ~/work/lasercube-local
python3 app.py --open
```

起動したターミナルでControl+Cを押すと終了します。
すでに起動している状態でも、起動.commandは同じアプリの画面を開きます。

## まずデモで試す

1. 出力先の「デモ」を選びます。起動直後は必ずデモです。
2. 円・8の字・三角形・赤い手形を切り替え、明るさ・大きさ・動く速さ・色を変更します。
3. 「デモを開始」で開始と停止を確認します。初期設定では停止操作まで継続します。デモは本体に出力命令を送りません。

## APC40の接続と割り当て

1. APC40をUSBでMacへつなぎます。
2. Chrome / Edgeで画面を開き「MIDIを接続」を押し、MIDIアクセスを許可します。
3. 機器一覧からAPC40を選びます。接続されていれば自動的に優先選択します。
4. 「明るさ」などの操作を選び「操作を覚える」を押します。
5. APC40のフェーダー・ノブ・ボタンを1つ動かすと割り当てられます。

明るさ・大きさ・速度・わらわら度にはフェーダー／ノブ、開始・停止・図形切替にはボタンを使ってください。
MIDIチャンネルとCC／ノート番号で対応付けるため、APC40とAPC40 MKIIのどちらにも対応します。
割り当てはそのブラウザのローカルストレージへ保存します。APC40へのLEDフィードバックは未実装です。
APC40の実機入力は、接続後に「最後の入力」の値が変わることで確認できます。

## 赤い手形のホラーモード

「赤い手形」を選ぶと赤色に変わり、左右の手の輪郭がゆっくり揺れ、濃くなったり薄くなったりします。
「わらわら度」は手の数（1〜8体）です。増やすと同時に描く手が増えます。
実機はレーザーによる輪郭描画です。手の数が増えるとちらつく場合があります。

APC40のおすすめ割り当ては画面の「どこを動かすと、どうなる？」にも表示しています。

| APC40の操作 | 割り当て | 動き |
| --- | --- | --- |
| 左端のフェーダー | わらわら度 | 手の数1〜8体 |
| 左から2本目のフェーダー | 明るさ | 暗く／明るくする |
| 左から3本目のフェーダー | 大きさ | 手形の群れ全体を拡大／縮小 |
| 使いやすいノブ1つ | 動く速さ | 手の揺れと明滅をゆっくり／速くする |
| 左上のクリップボタン | 開始 | 停止操作まで継続 |
| その真下のクリップボタン | 停止 | 出力を停止 |

各行の「割り当て」を押してから、該当するAPC40の箇所を動かして覚えさせます。
初期状態でAPC40の固定番号に自動割り当てする方式ではありません。

## LaserCube実機

1. Mac → USB-Cハブ → LANケーブル → LaserCubeのLAN端子へ接続します。
2. 本体をLAN Serverモードにします。Macの有線LANはDHCP（自動取得）を使います。
3. インターネットと併用するときは、Macのネットワークサービス順序でWi-Fiを有線LANより上にします。
4. 接続欄にモデル名と温度が表示されることを確認します。初期接続先は192.168.1.1です。
5. 他のレーザー制御アプリを終了し、投影先と緊急停止手段を確認します。
6. 「LaserCube実機」を選び、確認欄をチェックして「実機への出力操作を許可」を押します。
7. 「実機出力を開始」で開始します。停止ボタンまたはEscapeキーで停止できます。

初期明るさ1%、上限5%、図形サイズ5〜30%、最大12000ppsに制限しています。
実行時間の初期値は「停止するまで」です。必要に応じて5秒・15秒・30秒のタイマーを選べます。
この値は目の安全を保証するものではありません。低出力でも危険です。
本体のインターロックが未有効、過熱停止フラグがON、機器への応答なしの場合は開始できません。
温度警告フラグは画面に表示します。警告だけでは開始を禁止せず、過熱停止フラグがONになったときは実行中の出力も停止します。
画面の接続が3秒以上途切れたとき、タイマーを選んだ場合の指定時間終了時、サーバー終了時にも停止命令を送ります。
各フレームの先頭と末尾は消光した点を送ります。
OSの停止・電源断・ネットワーク断などでソフトウェア停止命令が届かない場合があるため、本体の緊急停止手段を使用してください。

初版は図形送信とMIDI入力に絞った実装です。メーカーアプリと同じ投影範囲・安全ゾーン・光学補正は提供しません。
APC40で開始を割り当てても、実機モードでは先に画面で出力操作を許可する必要があります。

## OSCで別アプリとつなぐ

画面下部の「アプリ同士をつなぐ」で設定します。起動時は送信・受信ともOFFです。
この版は同じMac内の127.0.0.1で通信します。別PCからの受信や別PCへの送信には未対応です。

### APC40 → 別アプリへ送信

1. MIDI接続を済ませ、「APC40の操作を別アプリへ送る」をONにします。
2. 送信先ポートを指定します。初期値は9001です。
3. 「設定を適用」を押します。
4. 相手アプリをUDPポート9001でOSC受信する設定にします。

MIDIの割り当ての有無にかかわらず、選択中のMIDI機器の入力を送ります。

| 入力 | OSCアドレス例 | 引数 |
| --- | --- | --- |
| CH1のCC7 | `/apc40/cc/1/7` | 0〜1のfloat |
| CH1のノート53 | `/apc40/note/1/53` | 0〜1のfloat（離すと0） |

連続するCC入力は最大約60回/秒にまとめ、最後の値を送ります。ボタンの押下・解放は個別に送ります。

### 別アプリ → LaserCubeへ受信

1. 「別アプリからLaserCubeを操作する」をONにして「設定を適用」を押します。
2. 相手アプリのOSC送信先を127.0.0.1、UDPポート9000にします。
3. デモモードで値が画面へ反映されることを確認します。

| OSCアドレス | 引数 | 動作 |
| --- | --- | --- |
| `/laser/brightness` | float 0〜1 | 明るさ0〜5% |
| `/laser/size` | float 0〜1 | 大きさ5〜30% |
| `/laser/speed` | float 0〜1 | 回転速度0〜1回転/秒 |
| `/laser/shape` | string | `circle` / `eight` / `triangle` / `hands` |
| `/laser/density` | float 0〜1 | 手形の数1〜8体 |
| `/laser/colour` | string | `#57e5dc`などのRGB色 |
| `/laser/duration` | intまたはfloat | 0なら停止するまで継続、5〜30なら指定秒数 |
| `/laser/next` | なし、または1 | 次の図形 |
| `/laser/start` | なし、または1 | 開始 |
| `/laser/stop` | なし、または1 | 停止 |

実機の出力許可は引き続きブラウザ画面で行います。OSCから出力許可を有効にする機能はありません。
即時実行のOSC bundleにも対応します。未来時刻のスケジュール、アドレスのワイルドカード、全OSC型には対応していません。
OSC入力は最大400メッセージ/秒です。送受信のポート番号は別々にします。

受信をONにした後、ターミナルから次の例で回転速度を変更できます。出力開始の命令は送りません。

```sh
cd ~/work/lasercube-local
python3 -c 'import socket; from osc_protocol import encode_message; socket.socket(socket.AF_INET,socket.SOCK_DGRAM).sendto(encode_message("/laser/speed",[0.3]),("127.0.0.1",9000))'
```

## 検証

```sh
python3 -m unittest -v test_laser.py test_osc.py
osascript -l JavaScript test_midi.js
```

テストはループバック上の仮想LaserCubeと通信します。実機を発光させません。
実機との情報取得は確認済みですが、今回の開発中に実機への発光テストは実行していません。
